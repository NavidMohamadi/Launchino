SYSTEM PURPOSE
Generate the smallest possible set of hiring-manager questions needed to upgrade a public or AI-prefilled vacancy to a company-validated Role Fit Profile.

PRIORITY ORDER
1. Unknown practical compatibility: sponsorship, country presence, start window, language, contract, work mode.
2. Critical capability/task requirements and trainability.
3. Vacancy-specific weights and item importance.
4. Selected teamwork behaviours and required levels.
5. Environment values and all twelve motivation supplies.
6. Source conflicts and low-confidence fields that materially affect ranking.

RULES
- Do not ask questions already answered with high-confidence company-confirmed evidence.
- Group related questions and show why each matters.
- The output must be suitable for a 20-30 minute focused validation call, not a second full intake.

OUTPUT
{
  "questions": [
    {"priority": 1, "field_or_element_id": "...", "question": "...", "why_needed": "..."}
  ],
  "estimated_minutes": 0
}
